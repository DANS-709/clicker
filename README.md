# PyQt6 Autoclicker

## Основные возможности

1. **Два режима работы:**
   - **В текущем положении:** непрерывные клики в текущей позиции курсора.
   - **Перебор сохраненных:** циклический перебор заранее сохраненных точек (координат X и Y).
2. **Управление координатами:**
   - Сохранение текущей позиции курсора в таблицу.
   - Автоматическое ограничение максимального количества точек (с удалением старых при переполнении).
   - Частичное (удаление выбранных строк) или полное очищение таблицы.
3. **настройки и возможности**
   - Регулировка интервала между кликами (в секундах).
   - Настройка максимального количества сохраняемых точек.
   - Кнопки **Старт/Стоп**, **Сохранить позицию** и **Сменить режим** можно переназначать прямо из интерфейса, кликнув по соответствующей кнопке настройки и нажав нужную клавишу на клавиатуре.

---

## Запуск и использование

1. **Запустите приложение**:
   - Запустить clicker.exe
2. **Настройка режимов:**
   - Выберите нужный режим с помощью радиокнопок (`В текущем положении` или `Перебор сохраненных`).
3. **Сохранение точек (для второго режима):**
   - Наведите курсор в нужное место экрана и используйте назначенную горячую клавишу.
4. **Запуск и остановка:**
   - Нажмите кнопку **Старт/Стоп** в интерфейсе или используйте глобальную горячую клавишу старта.
5. **Безопасность:**
   - Если нужно экстренно остановить автокликер, то переместите курсор мыши в любой из четырех углов экрана.
